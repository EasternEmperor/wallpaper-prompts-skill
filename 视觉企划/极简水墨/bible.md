# 极简水墨 · 定位圣经

## 母定位宣言

仅用黑色线条模拟水墨画：白底之上，一个角色 + 一个意象，一笔见意境。粉丝收藏的是"留白里的那个人"。

## 风格 DNA 固定块（positive，逐字复用，禁止改动）

```
minimalist sumi-e style ink wash illustration, black ink lines only, monochrome black and white, vast negative space, pure white background, single brushstroke elegance, clean simple background, minimalist uncluttered composition, 3:4 vertical portrait wallpaper
```

```
color, colored, gradient color, any color tint, cluttered background, busy background, overly detailed background, stacked overlapping elements, excessive glowing particles, light effects, bokeh, messy composition, photorealistic, 3d render
```

## 封面图规范（每期 1 张，固定位）

1. **构图**：杂志封面式水墨肖像，3:4 竖版；角色以四分之三侧面半身像（three-quarter bust portrait）面向观者，当期意象以单笔触点缀（如肩后一线远山 / 几笔雨线 / 一枝梅），其余大留白。
2. **封面文字（固定元素）**：刊名 `EEAnime` 以小号艺术字呈现——手绘水墨笔触字效（hand-painted ink brush lettering），字母自上而下竖排、沿封面右上侧边缘排列，尺寸小巧不抢主体；人物英文名大写（如 `ZHONGLI` / `GANYU` / `HU TAO`）以小号黑色衬线字置于下方留白处。
3. **Negative 特例**：封面 negative 基线**删除 `text` 项**（报头与角色名是需要保留的文字），另加 `distorted letters, misspelled text, extra text` 控字体质量；其余负面项与人体穷举块照常复用。
4. **自检**：封面不计入正文自检计数 N；封面无审查敏感词、无彩色项，其余同正文标准。

## 禁入清单

- 任何彩色、渐变、发光特效——单色是本系列生命线
- 复杂背景、多意象堆叠（一期一意象）
- 卡通 Q 版化处理（保持水墨笔意）
