# Prompts 模板参考

本文件为四种视频类型分别提供 prompts.md 的模板格式。

---

## 类型 A：角色单人壁纸合集

```markdown
# {角色名} {Character Name} — {YYYY.MM.DD}
> 视频类型：A · 角色单人壁纸合集
> 角色来源：{游戏名} {版本号} · {星级}{元素}属性{武器类型}
> 身份：{角色身份/背景}
> 设计参考：{角色设计灵感来源}
> 热点背景：{选择该角色的热点原因}
> 今日特殊：{如有节日/赛事等特殊主题，注明}

# 必需
![alt text](../../needful.png)

{涂鸦墙街头现代风 Positive Prompt —— 1 张}
- 引用 needful.png 作为风格参考
- 现代街头服饰（短上衣+外套+短裤/裙等）
- 涂鸦墙背景，色调匹配角色主色
- 冷漠/不屑/高傲表情

Negative Prompt: {标准排除项}

# 人物设定

## 1 — {场景主题}

Positive Prompt:
{完整正向提示词：比例、角色名、画风、外貌、服装、动作、表情、场景、光影、色调}

Negative Prompt:
{针对性排除项}

## 2 — {场景主题}
...（共 3~4 条角色设定 + 1~2 条现代风 + 1~2 条战斗 + 1 条日常反差 + 0~1 条热点特别版）

# 参考图

## {N+1}（{参考图用途说明}）
![alt text]({参考图文件名})
{基于参考图的 prompt}

Negative Prompt: {排除项}

## {N+2}（手机竖屏壁纸）
![alt text]({参考图文件名})
{9:16 2K 手机壁纸适配 prompt}

Negative Prompt: {排除项}

# 跨领域参考图

## {N+3}（参考{真实世界素材描述}·{融合方式}）
![alt text](ref-{描述}.jpg)

Positive Prompt:
{融合 prompt：参考来源、参考元素、角色保持设计清晰度、环境融合参考风格、元素能力增加独特变化}

Negative Prompt: {排除风格冲突项}
```

## 类型 B：主题类型合集

```markdown
# {主题名} — {YYYY.MM.DD}
> 视频类型：B · 主题类型合集
> 主题说明：{主题描述}
> 热点背景：{为什么选这个主题}
> 涉及角色：{角色1}、{角色2}、{角色3}...

## 1（{角色名}）
![alt text]({参考图，如有})

Positive Prompt:
{最详细的一条，定义整体风格基调}
- 画面比例、画风
- 角色外貌特征（发色发型、瞳色、标志性配饰）
- 主题服装描述（具体到款式颜色，体现主题）
- 动作与表情
- 场景/背景（统一主题场景）
- 角色主色配色方案

Negative Prompt: {排除项}

## 2（{角色名}）
![alt text]({上一张生成图，作为风格参考})

Referring to the attached image, generate a similar {主题} image for {角色名} from {游戏名}.
- 保留该角色的标志性特征：{发型、发饰、尾巴等}
- 服装/配色调整为：{该角色的主色方案}
- 其余构图、背景、风格与参考图保持一致

Negative Prompt: {排除项}

## 3~N（后续角色格式同上）

## 注
{补充信息，如角色人气榜排名、选角理由等}
```

## 类型 C：可爱动物萌化形象合集

```markdown
# 萌宠-{动物}系列 — {YYYY.MM.DD}
> 视频类型：C · 可爱动物萌化形象合集
> 动物类型：{猫猫/兔兔/etc}

## 1（{角色名}）
![alt text]({参考图，如有：角色立绘或设定图})

{Prompt 要点}：
- 画面比例：16:9 2K wallpaper
- 动物品种：根据角色气质选择（如高冷→布偶猫、活泼→橘猫）
- 毛色 = 角色主发色
- 必须保留：标志性头饰/配饰、瞳色、呆毛/特殊发型特征
- 移除：人类衣服、人类头发（除非极度标志性）
- 可保留：项圈/颈饰、小帽子
- 可添加：角色相关小道具/玩具（召唤物缩小版等）
- 背景：简洁，匹配角色性格和主色调，不过于复杂

Negative Prompt: {排除项}

## 2（{角色名}）
![alt text]({上一张生成图，作为风格参考})
![alt text]({该角色的立绘参考，如有})

参考上一张生成的{动物}图片风格，为 {角色名} 生成同系列的{动物}形象。
- 毛色：{角色主色}
- 保留特征：{标志性配饰}
- 背景：{简洁背景描述}

## 3~N（后续角色格式同上）
```

## 类型 D：表情包合集

```markdown
# {角色名}·{形象类型}表情包 — {YYYY.MM.DD}
> 视频类型：D · 表情包合集
> 角色：{角色名}（{游戏名}）
> 形象类型：{猫猫化/Q版/正常形象/etc}

## {表情名称}
![alt text]({设定图/参考图，首条必须有})

{Prompt 描述}：
- 画面比例：1:1
- 表情：{面部表情细节描述}
- 动作：{肢体姿态描述}
- 文字：{如有玩梗文字，注明内容和位置}
- 背景：{简洁或纯色}

## {表情名称}
{后续表情无需重复设定图，保持同一形象}
{Prompt 描述}

...（共 8~12 个表情，建议覆盖：得意、疑惑、惊慌、无语、喜欢、顿悟、思考、生气、哭泣、偷笑、加油、摆烂）
```

## 类型 E：梗图合集

```markdown
# {梗图主题} — {YYYY.MM.DD}
> 视频类型：E · 梗图合集
> 主题说明：{梗的来源和概念，如"蜜雪冰城雪王梗——冰女皇变成蜜雪冰城吉祥物形象"}
> 热点背景：{为什么选这个梗，社区传播情况}
> 涉及角色：{角色1}·{梗形象1}、{角色2}·{梗形象2}、{角色3}·{梗形象3}...

## 1（{角色名}·{梗形象名}）
![alt text]({参考图，如有：角色立绘或梗来源图})

Positive Prompt:
3:4 比例，{角色名} from {游戏名}，highly detailed illustration，{梗形象概念描述}。

{梗形象的完整描述}：
- 梗概念：{梗的来源，如"蜜雪冰城雪王吉祥物风格"}
- 保留角色特征：{发色发型、瞳色、标志性配饰}——这些必须保留让观众认出是哪个角色
- 梗风格造型：{完全改变服装/体型/气质为梗的风格，如"圆润雪王身材、白色绒毛、红色围裙、拿着冰淇淋权杖"}
- 动作与表情：{夸张、有梗感的动作和表情}
- 背景：{简洁或与梗相关的场景}
- 梗相关文字/标志：{如有，注明内容和位置}

Negative Prompt:
{排除与梗冲突的元素，如做搞笑梗时排除 serious, dark, edgy；排除画质问题、人体结构问题、其他角色等}

## 2（{角色名}·{梗形象名}）
![alt text]({上一张生成图，作为风格参考})
![alt text]({该角色的立绘参考，如有})

参考上一张图的风格基调，为 {角色名} 生成同系列的梗形象图。
- 梗概念：{该角色的梗}
- 保留特征：{该角色的标志性特征}
- 梗风格造型：{该角色的梗形象描述}
- 动作与表情：{梗感动作}
- 背景：{场景}

Negative Prompt: {排除项}

## 3~N（后续角色格式同上）

## 注
{梗的来源说明、角色选择理由、社区热度参考}
```
