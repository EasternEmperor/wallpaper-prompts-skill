# 类型 G：视觉定位系列

账号级长期企划：选定一个强辨识度的视觉母定位（如「把二次元角色放入世界摄影名场景」），在母定位下持续产出「角色 × 子场景」系列图。粉丝追的不是单张图，而是「这个定位下一张会怎么玩这个角色」。

## 触发边界

- **新系列立项**：仅限用户当次手动确认，每日定时任务不得自动立项（与类型 F 同级红线）。
- **已有系列续更**：工作区存在激活中的定位圣经（bible.md）时，自动化可按流程续更下一期。
- 可与 A~F 混排：系列更新不必占用每一天，按 bible 中的更新节奏执行。

## 背景简洁强制条款（所有 G 系列硬性约束）

任何 G 系列的画面背景必须保持简洁：**禁止冗杂元素、禁止元素堆叠、禁止发光点/光斑过多**。

- Positive Prompt 固定含：`clean simple background, minimalist uncluttered composition`
- Negative Prompt 固定含：`cluttered background, busy background, overly detailed background, stacked overlapping elements, excessive glowing particles, excessive bokeh, light clutter, messy composition`
- 子场景设计留白：一个视觉主体 + 一个标志性背景元素即可，不选本身要求高密度元素的组合

## 第一步：视觉定位立项（五准则 + 打分表）

候选定位逐项打分（各 20 分，总分 ≥70 才立项）：

| 准则 | 判定要点 |
|------|----------|
| ① 视觉语言可固化 | 必须能提炼**色彩体系、光线语法、构图规则、器材/介质特征**四要素，且都能写成 prompt 短语。「浮世绘的平涂色块与描线」通过；「意境美、氛围感」等虚词不通过（一票否决） |
| ② 角色池交叉广度 ≥30 | 母定位与原神/崩铁/绝区零角色池的交集够深，保证选题矩阵 ≥30 条 |
| ③ 子场景可四维裂变 | 地点 × 季节 × 时刻 × 活动，母定位下至少裂变出 30+ 条不重复组合 |
| ④ 社区审美已验证 | 小红书/B站搜同风格关键词，有千赞爆款先例优先 |
| ⑤ 差异化 | 竞品检索确认该定位无人做或做得浅 |

参考候选池（仅示例，立项时需按五准则重新打分）：世界旅行摄影、各国电影美学（黑泽明/王家卫/韦斯·安德森）、浮世绘、70年代胶片摄影、夏夜自然光摄影等。

## 第二步：创建定位圣经 bible.md

新系列立项时，在 `视觉企划/{系列名}/bible.md` 写入以下结构。**bible 是系列唯一权威文档**，立项后只追加登记、不修改固定块：

```markdown
# {系列名} · 定位圣经

## 母定位宣言
一句话说清账号用这个定位做什么（如「把米哈游角色放入世界摄影名场景，每张都是一次『角色×名场景』的化学反应」）。

## 风格 DNA 固定块（positive，逐字复用，禁止改动）
{相机/镜头/胶片/调色/光线语法/构图规则的完整 prompt 片段}

## 定位专属负面块（逐字复用）
{防止风格滑移的反向锚点，如实拍系列排除 anime screencap, cel shading；绘画系列排除 photorealistic, 3d render}

## 选题矩阵（≥30 条，立项时一次性生成）
| 编号 | 角色 | 子场景（地点×季节×时刻×活动） | 状态 |
|------|------|------------------------------|------|
| 001 | 流萤 | 夏夜×河谷×萤火虫纷飞×驻足回眸 | 未做 |

## 已产出登记表
| 期数 | 日期 | 模式 | 选题编号 | prompts.md 相对路径 |

## 禁入清单
{不符合定位的题材，如现代都市钢铁质感之于浮世绘系列}
```

选题矩阵生成规则：以「地点 × 季节 × 时刻 × 活动」四维交叉裂变，角色按人气与气质匹配度排入，确保每条组合中角色气质与子场景有化学反应点（如三月七×欧洲列车摄影的「旅人」气质）。

## 第三步：每期产出（3 张）

每期 prompts.md 固定 **3 条 prompt、统一比例 3:4 竖版**（`3:4 vertical portrait wallpaper`）。两种出图模式（二选一）：

**模式一 · 单角色三连**：同一角色 + 同一视觉定位，**3 张各不相同**的姿势、机位角度、着装（如同一场景的远/中/近三机位，或同角色三套着装）。适合当期有热点角色需要深度呈现时。

**模式二 · 多角色同构**：3 个不同角色 + 同一视觉定位，**姿势、机位角度相同，着装相似**（同款式不同配色），形成平行构图对照。适合日常续更，天然带「谁更适配这个场景」的讨论点。

模式选择记录在 prompts.md 头部注释中。

### Prompt 三层结构

每条 prompt 由三层拼装：

1. **风格 DNA 头部块**：从 bible 逐字复制，禁止任何改动——这是跨期视觉统一的指纹。
2. **角色 × 子场景块**（当期唯一变量）：角色全名与出处 + 外貌锚点 + 当期子场景描述 + 姿势/表情/眼神方向（按上方模式约束）。
3. **负面块**：通用负面（含手部/腿部穷举，见 SKILL.md 通用规范）+ bible 定位专属负面块逐字复制。

角色外貌锚点优先引用工作区已校对参考图（遵循 SKILL.md 参考图处理通用流程与 `reference-registry.md`），作用域条款写法：

> `Referring to the attached artwork for character appearance only, generate ...`

仅锁定角色外观，不复制参考图的姿态、服装、构图——构图必须服从本系列的风格 DNA。

### 执行流程

1. 读 bible → 确认激活状态
2. 从选题矩阵取**状态为未做**的选题（模式一取 1 条组合拆 3 张；模式二取 3 条同子场景不同角色的组合）
3. 按 SKILL.md 完成参考图下载/校对 → 按三层结构写 3 条 prompt → Phase 3 产出自检 → Phase 4 文案
4. 回填 bible：已产出登记表追加本条目，选题矩阵状态改为已做

### 扩题与退出

- **矩阵余量 <10 条时强制扩题**：裂变新维度（新地点/新时刻/新活动）或纳入新角色，扩充后更新矩阵
- **退出条件**（满足其一即冻结归档）：连续 3 期数据低迷；两次扩题后矩阵仍无法补足 30 条。冻结的 bible 保留归档，未来可经用户确认重启
