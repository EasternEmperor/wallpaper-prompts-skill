# 清纯风写真 · 定位圣经

## 母定位宣言

固定角色、一套五变的「系列写真棚」：每期 1 位角色 × 5 套造型（校园 JK / 水手服短裙 / 素色比基尼 / 睡衣风吊带 Slip / 甜酷风透视网纱）。校园 JK 沿用经典窗边半身原版格式（场景/构图/光线不变）；其余四套另设场景与景别（校门口石阶·膝上 / 泳池边·全身 / 床沿·膝上 / 水泥墙前·全身），五张以角色一致性与柔和自然光统一系列感。粉丝收集的是"同一个女孩的不同一面"。（2026-10-15 用户要求：自本期起每期增至 5 张，ep04/ep05 已回补条目 4/5）

**固定不变项**（跨期逐字复用）：anime 风格 DNA 块、3:4 竖版、背景简洁强制条款、柔和自然光暖色调、角色官方参考图锁外观（不复制服装/姿势/构图）、负面块基线与人体穷举块。

## 风格 DNA 固定块（positive，逐字复用，禁止改动）

```
masterpiece anime-style illustration, clean simple background, minimalist uncluttered composition, standing by a classroom window in the afternoon, pale minimalist wall, softly blurred greenery outside the window, soft natural side window light, gentle warm tones, highly detailed, 3:4 vertical portrait wallpaper
```

条目 1（校园 JK）逐字复用该 DNA 原版格式（窗边·半身回眸）；条目 2（水手服）、条目 3（泳装）、条目 4（睡衣风）、条目 5（甜酷风）保留 DNA 其余部分，仅将场景段替换为各自场景（2026-10-07 第 3 期起改版，2026-10-15 第 4/5 条目增补）。

## 背景固定枚举规则（防 AI 自由发挥，2026-10-07）

1. 每条 prompt 的背景必须枚举固定为 ≤3 个朴素元素，逐个写明颜色/形态/位置，并以 `no other background elements` 收口。
2. 禁止场所类开放词（pool / sea / beach / campus / resort 等）单独充当背景描述——AI 会自行堆叠棕榈树、躺椅、遮阳伞、建筑等元素，导致人物与背景不协调。
3. 五套条目固定背景清单：JK = 原版 DNA（教室窗 + 浅色墙 + 窗外绿意虚化）；水手服 = 脚下灰色石阶 + 身后浅米色平墙（左端一根深色木门柱）；泳装 = 白瓷砖池边 + 身后平坦淡蓝池水面；睡衣风 = 白床品床沿 + 身后浅米色平墙；甜酷风 = 身前平坦浅灰水泥墙（大腿根部以上取景，让视线聚焦短裤拉链/扣细节；2026-10-15 二次调整，原全身景别已废弃）。
4. 水手服条目负面块在 `worst quality,` 后追加 `trees, plants, signage, ornaments, buildings,`；泳装条目追加 `palm trees, parasols, beach umbrellas, deck chairs, resort furniture, tables, plants, buildings, sea, mountains,`；睡衣风条目追加 `scattered pillows, stuffed toys, plushies, bedside lamps, posters, framed pictures, plants, windows,`；甜酷风条目追加 `storefronts, neon signs, graffiti, vehicles, street furniture, passersby, plants,`。

## 定位专属负面块（逐字复用）

```
cluttered background, busy background, overly detailed background, stacked overlapping elements, excessive glowing particles, excessive bokeh, light clutter, messy composition
```

## 禁入清单

- **未成年外形成年角色一律禁入本系列**（白露仅限 JK 条目且为合法校园着装语境，严禁任何泳装/暴露向处理）；比基尼条目仅限上表指定的明确成年外形角色
- 任何暴露、暗示性姿势；尺度红线（nude/topless/explicit 等）永久生效
- 背景使用场所类开放词（泳池/大海/校园/度假村等）而非固定元素清单
- 每期五张必须同角色、同 3:4 竖版、同风格 DNA、同负面块基线；不得五张同场景同景别同姿势（避免单调）；比基尼仅限素色保守款式 + 防晒开衫语境；睡衣风条目限及膝保守长度 slip 裙；甜酷风条目网纱必须浅白色（禁黑色，画面会发暗）+ 圆领、内搭必须写明单色比基尼式 bandeau 上衣收口（仅包胸部、只此一色，不再用束腰长胸衣）+ positive 带 `tasteful and elegant fashion styling, no explicit content`（2026-10-15 三次微调定稿）
- 白露仅限 JK 条目：睡衣风/甜酷风/泳装条目对未成年外形角色一律禁入（不因新增条目放宽）
