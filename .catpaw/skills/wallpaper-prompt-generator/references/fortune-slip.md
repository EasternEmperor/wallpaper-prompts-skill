# 签图系列生成指南（类型 F 详细规范）

本文件是 SKILL.md「类型 F：签图系列」的完整执行逻辑。生成任何签图前必须通读本文。

---

## 触发红线（最高优先级，不可绕过）

- 签图**只能在用户当次明确指定时生成**（如「生成一版签图」「再做一期抽签壁纸」「参考某某签图系列出一版」）。
- **每日定时任务（automation）严禁自动产出签图**：automation 的 prompt 中不得包含任何签图生成指令；定时任务的范围仅限类型 A~E。
- 签图的风格基调、张数、三游戏分配、比例由用户当次指定；未指明的部分先与用户确认，不要自行拍板。
- 即使用户在对话中提到「签图」相关关键词，也只在其明确要求生成时才动手，平时只做答疑或引用。

---

## 第一步：读已有系列定基准

动笔前**必读**工作区已有的签图系列，理解其模板构成与文案格式：

| 系列目录 | 风格基准 | 学习点 |
|---------|---------|--------|
| `主题类型/月谕圣牌-十二月相抽签塔罗/prompts.md` | 统一像素风塔罗牌 | 框架元素全系列逐字复用、仅角色互换的「模板化」做法 |
| `主题类型/风物签-吉卜力风九签/prompts.md` | 吉卜力手绘圆窗纸签 | 「三固定一变化」公式、探窗姿势、签文三件套与落地说明验收清单 |

新签图必须**建立自己的一套固定模板**（新风格），不得混用或微改已有系列的模板；模板句式可参考上述系列的写法（固定句逐字复用 + 变量句按角色替换）。

---

## 系列统一铁律：「三固定一变化」

签图是**成套收藏品**，系列记忆点来自模板统一，不是单张精美：

1. **固定**：纸张底色、边框、角落装饰物、卷轴、印章等框架元素——描述这些元素的句子在全部 prompt 中**逐字复用**（一字不差），写作时可先写好模板句再复制。
2. **变化**：每签只有「圆内/框内主题物」随角色变化——为每个角色设计一个专属小物件或微场景（与角色强关联），且各签主题色全系列形成有意的色谱序列（如 绿→黄→红→碧→蓝→靛→橙→粉→金）。
3. **姿势统一**：全系列角色使用同一个低风险姿势，写法逐字复用（如风物签的探窗姿势：双手平放窗沿、头与单肩微微越出圆框）。

**定稿流程**：先只生成第一条并让用户确认定稿 → 后续各签以第一条为底图 **img2img 低重绘幅度**，只替换圆内主题与角色，保证框架像素级一致。

**反面案例（2026.09.21 风物签 v1）**：每张独立构图、各画各的完整场景，用户评价「没有记忆点，风格不一」，与月谕圣牌的统一像素风对比后被整版打回重做。**教训：签图先设计模板公式，再填角色；不要先画场景再找统一感。**

---

## 签文三件套（只写 markdown，图片零文字）

每签在 prompts.md 中包含三件文案，**图片内部绝对不出现任何文字**：

1. **签名**：四字签题，必须**嵌系列模板关键字**（如圆窗系列九个签名全部嵌「窗」字），与视觉模板互为呼应，形成文案层的系列记忆点。
2. **签位**：吉凶等第（如 生签/中吉/上吉/大吉/上上签），全系列分布要有轻重设计（避免全是上上签），供抽签类视频做抽签手感。
3. **签语**：1~2 句短句，必须呼应该签圆内主题物（画面里有什么物件，签语就写什么意象）；**纯中文**，不留英文单词混入。

**图片零文字纪律**：

- prompt 中明确：卷轴与印章一律留白（blank scroll / blank vermilion seal, no characters, no letters, no marks）
- negative prompt 统一追加 `text, watermark, logo, signature` 及假名/字母/数字排除
- 签名/签位/签语由**后期统一加字**，保证九签字体、排版完全一致；prompt 中注明后期加字的位置建议（如签名+签位写卷轴，签语放字幕/抽签页）

**反面案例（2026.09.21 风物签 v2）**：画面模板推倒重做后，签名/签语原样沿用旧版，被用户指出「签名和签语好像没有变化？」——旧签文描述的是已不存在的 v1 场景。**教训：画面改版必须连签文一起重写，签文永远描述当前版本的圆内主题物。**

## 默认规范（用户当次指定可覆盖）

- **比例**：9:20 竖版手机壁纸（2026-09-18 定稿规范）；历史系列中的 3:4 / 9:16 仅作旧档参考，不再使用。
- **游戏分配**：三游戏（原神/崩铁/绝区零）均衡覆盖；具体张数与每游戏张数由用户指定（如 9 张 = 3+3+3）。
- **角色去重**：
  - 不与近期签图系列的角色重复。查重基准——月谕圣牌 12 人：胡桃、芙宁娜、钟离、温迪、卡芙卡、流萤、黑天鹅、三月七、星见雅、艾莲、妮可、安比。
  - 同一签图系列内角色不重复。
  - 生成前列出「新系列角色 × 已用系列」对照清单放在 prompts.md 头部或落地说明中。

## 参考图（与类型 A 同标准）

1. 按类型 A 的四级下载链路（B站WIKI API → WIKI 页面解析 → 萌娘百科 → 纯文本兜底）获取每个角色的官方立绘，存入系列目录 `refs/`。
2. **必须用视觉工具逐张看图校对**外貌锚点（发色/瞳色/发型/配饰/耳角/尾巴等），严禁凭印象写。
   - 反面案例：万叶被凭印象写成深发色，实际是灰白发 + 单缕红色挑染、发尾红渐变——靠逐张看图才纠正。
   - 立绘文件名不存在时（如朱鸢立绘缺失），改用 `generator=images` 查角色页全部图片（如「代理人档案」图）。
3. 工作区其他角色目录下已有的参考图可直接复用（相对路径引用），不重复下载。

---

## 手部与姿势

- 全系列统一**一个**低风险姿势（如双手平放窗沿/双手扶框），写法逐字复用；角色专属道具移入圆内展示，避免复杂持握。
- negative prompt 保持手部穷举全集（同类型 A）+ 零文字排除项。

---

## 目录与文件结构

```
主题类型/{签图系列名}/
├── prompts.md     # 每签一段：## 序号 · 角色｜签名 → 签位 → 签语 → 参考图 → Positive → Negative
├── titles.md      # 可选，视频发布文案
└── refs/          # 角色参考图（{角色名}-official.png 等）
```

**prompts.md 末尾必须附「落地说明」**，包含：

- 系列验收清单：明确列出「全系列只有哪几处不同」（如风物签：只有圆内主题物、主题色、角色本体三处不同，其余全部逐字相同）
- img2img 定稿流程（以第一条为底图）
- 后期加字规范（加什么字、加在哪、字体统一原则）
- 签文速查行（序号 角色「签名」签位 一行流，方便做抽签视频时快速取用）
- 角色去重对照与季节/时事备注（如有）
